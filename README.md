# ThaiFit AI

A Thai-first nutrition and workout tracking app
focused on AI-powered Thai food recognition.

## Overview

ThaiFit AI aims to help users track their nutrition
and workouts, with a focus on recognizing Thai dishes
from food photos.

## Current Features

- Initial mobile app prototype
- Food photo recognition experiment

## Tech Stack

- React Native
- Expo
- TypeScript

## Project Status

Early-stage prototype in development.

## Planned Features

- Thai food nutrition estimation
- Editable food portions and ingredients
- Daily nutrition tracking
- Workout logging
- Custom Thai food recognition model
